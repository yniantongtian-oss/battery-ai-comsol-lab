# Research Program

## Scientific layers

### Cell electrochemistry

Start with SPM/SPMe/DFN baselines and quantify the incremental value of complexity. Primary observables are terminal voltage, electrode/electrolyte concentration fields, reaction overpotentials, and degradation states.

### Thermal physics

Validate heat-generation and thermal-response models separately before coupling to full 3D geometry. Distinguish reversible, irreversible and ohmic contributions where the parameter set supports them.

### Mechanics

Study diffusion-driven expansion, particle/electrode stress and structural constraints only after concentration fields have been validated.

### Ageing

Treat SEI, plating, LAM and impedance growth as competing hypotheses that require identifiability analysis and long-horizon validation.

### Pack/system

Introduce cell-to-cell variability, interconnect resistance, sensor topology and cooling asymmetry. Avoid using pack-level fits to hide incorrect cell physics.

## Cross-cutting methods

- global/local sensitivity analysis
- parameter identifiability
- uncertainty quantification
- experiment/model alignment
- residual diagnostics
- model-selection criteria
- reproducible data lineage

## Primary deliverables

1. Reference cell model suite.
2. COMSOL multiphysics model cards.
3. Validated parameter library.
4. Experiment dataset registry.
5. Physics-to-surrogate training pipeline.
6. BMS/digital-twin demonstrator.
7. Pack thermal/electrical demonstrator.
8. Publication-ready validation reports.
