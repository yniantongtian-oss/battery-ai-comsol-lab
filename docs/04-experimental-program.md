# Experimental Program

## Core characterization

- capacity/energy characterization
- OCV/SOC characterization
- pulse/HPPC-style tests for dynamic resistance
- EIS where equipment is available
- GITT/PITT where parameter identification requires it
- controlled thermal characterization
- cycle/calendar ageing matrices

## Data acquisition requirements

Record cell ID, chemistry, form factor, test channel, current, voltage, temperatures, environmental condition, sampling interval, protocol revision, equipment calibration state and operator notes.

## Replicates

Use replicate cells for claims about degradation or temperature-dependent behavior. Keep raw data immutable and version preprocessing separately.

## Safety

Experimental abuse/failure studies require institutional procedures, suitable facilities and trained supervision. This repository does not define dangerous test procedures.
