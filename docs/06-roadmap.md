# Roadmap

## Phase A — foundation (implemented in v0.1.0)

- repository/data standards
- PyBaMM runner
- electrochemical/electro-thermal baselines
- sweep engine
- COMSOL bridge
- CI/tests
- ECM/digital-twin primitives
- surrogate/Pareto utilities

## Phase B — validated cell model

- select target commercial/research cell
- gather datasheet + experimental characterization
- parameter identification
- electrochemical validation
- thermal validation
- uncertainty budget

## Phase C — COMSOL 3D model

- geometry and tabs
- anisotropic thermal properties
- electrochemical heat sources
- mesh convergence
- PyBaMM/COMSOL cross-validation

## Phase D — degradation + AI

- ageing experiment registry
- competing degradation mechanisms
- SOH/RUL baselines
- surrogate dataset generation
- active learning and UQ

## Phase E — BMS / digital twin / pack

- calibrated ECM
- SOC/SOH estimators
- online parameter adaptation
- module variation
- thermal management optimization
- observability/sensor studies

## Phase F — publication/release

- reproducible figures/tables
- paper-reproduction notebooks
- dataset/model cards
- versioned release and archived artifacts
