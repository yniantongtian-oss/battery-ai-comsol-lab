# Publication Checklist

Before treating a result as publication-ready:

- [ ] exact code commit recorded
- [ ] config and parameter source archived
- [ ] raw-data provenance documented
- [ ] units/sign conventions defined
- [ ] validation metrics reported
- [ ] train/validation/test leakage excluded
- [ ] uncertainty/replicates addressed
- [ ] competing baseline included
- [ ] mesh/time-step sensitivity checked where relevant
- [ ] figures generated by script
- [ ] third-party licenses/citations included
